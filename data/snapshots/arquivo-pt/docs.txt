 Arquivo.pt API 
 Jump to bottom 
 Edit 
 New page

 The Arquivo.pt API allows full-text search over the web pages and documents preserved by Arquivo.pt, from 1996 onwards, and access to their content and metadata. It can also list every preserved version of a URL.
The API returns JSON and can be called directly from a browser, as it allows cross-origin requests (CORS). 
 Endpoint : https://arquivo.pt/textsearch 
 OpenAPI specification : https://arquivo.pt/textsearch/api-docs/v3 
 Try it out : the Swagger playground lists every parameter and lets you send requests to the API from the browser. 
 Note: a full-text search returns a maximum of 500 results per request ( maxItems ); use offset to page through more. 
 The API can be used in three ways, each with its own parameters: 
 Search for terms (full-text search), with q . 
 Search for URL , with versionHistory , to list the preserved versions of a URL. 
 Search for metadata , with metadata , to get the details of one preserved version. 
 The extracted text of a preserved version is available on a separate endpoint. 
 Request Parameters 
 Search for terms 
 Parameter Name 
 Description 
 Examples 
 q 
 Query search terms. Every term must match, so adding terms narrows the results. The query can contain advanced search operators: 
 " " : search for items containing the exact expression between quotes (e.g. a phrase or a named entity). 
 - : excludes the items that contain the given term. 
 Do not input URLs in parameter q because it will return an HTTP 400 Bad Request error. Use the versionHistory parameter to search for URLs, or alternative APIs that support URL search: CDX-server API , Memento API . 
 q=James Davis           q="António Costa" q=Albert -Einstein 
 from 
 Only return pages captured on or after this date. Format: YYYYMMDDHHMMSS, also accepts a shorter date (e.g. YYYY or YYYYMMDD), which is completed with the start of that period: from=2005 means from 1 January 2005. Default: no lower limit. A page is matched by its most recent capture, so a page first captured before this date can still be returned if it was captured again on or after it. 
 from=2005 
 to 
 Only return pages captured on or before this date. Format: YYYYMMDDHHMMSS, also accepts a shorter date, which is completed with the start of that period: to=2006 means until 1 January 2006, 00:00:00, so it leaves out 2006. To include a whole year or day, give the full timestamp, e.g. to=20061231235959. Default: no upper limit. A page is matched by its oldest capture, so a page also captured after this date can still be returned if it was first captured on or before it. 
 to=20061231235959 
 type 
 Only return documents of these types, as a comma-separated list (a document of any of them is returned). Case-insensitive. 
 pdf, doc/docx, xls/xlsx, ppt/pptx, ps/ai/eps, htm/html and rtf match the MIME types of those formats, e.g. doc matches both Word formats. 
 A value with a / is matched as an exact MIME type, e.g. application/pdf. 
 Any other value matches every MIME type containing it, e.g. opendocument. 
 type=pdf type=doc,xls type=application/pdf 
 siteSearch 
 Only return pages from these sites, as a comma-separated list (a page from any of them is returned). 
 A host matches that host only, not its subdomains: sapo.pt returns pages from sapo.pt but not from blogs.sapo.pt. 
 Prefix a host with *. to also match all of its subdomains: *.sapo.pt returns pages from sapo.pt and from any subdomain of it. The * wildcard is only supported as a *. prefix of a host. 
 A URL with a path matches every page whose URL starts with it, e.g. sapo.pt/noticias. 
 The protocol and a leading www . are ignored, so http://www.publico.pt , https://publico.pt and publico.pt are the same site. 
 When searching within a site, results are deduplicated by URL instead of by title (see dedupField). 
 siteSearch=publico.pt siteSearch=*.sapo.pt siteSearch=publico.pt,expresso.pt 
 collection 
 Only return results from these collections, as a comma-separated list. A trailing * matches every collection sharing a prefix, e.g. FAWP* matches FAWP1, FAWP2, ..., FAWP34. A list of all the collections preserved by Arquivo.pt is publicly available 
 collection=EAWP13,EAWP21 collection=FAWP* 
 titleSearch 
 Only return pages whose title is exactly this text. The match is case-sensitive: Expresso and EXPRESSO are different titles. 
 titleSearch=Expresso 
 language 
 Only return pages detected as being written in this language, as a two-letter code (ISO 639-1). 
 language=pt 
 minLanguageConfidence 
 Lowest language detection confidence the results may have: HIGH, MEDIUM or LOW. The levels are cumulative: MEDIUM also includes the HIGH results and LOW includes every result. Default: HIGH, when filtering by language. 
 language=en&minLanguageConfidence=MEDIUM 
 offset 
 Number of results to skip, to page through them. Default: 0 
 offset=50 
 maxItems 
 Maximum number of results per page. Default: 50 Max: 500 
 maxItems=10 
 dedupField 
 ⚠️ Warning: do not rely on this parameter. Its behaviour will change in upcoming releases, and support for custom dedup fields will be removed in the near future. Field the results are deduplicated by: for each distinct value, only the newest dedupValue results are returned. 
 title: pages with exactly the same title. 
 url: captures of exactly the same URL. 
 collection: results of the same collection. 
 type: results with the same MIME type. 
 site: currently behaves exactly like url (see #1619 ). 
 Default: title , or url when searching with siteSearch. 
 dedupField=url 
 dedupValue 
 Maximum number of results per distinct dedupField value. 0 and 1 both return one result per value. -1 turns deduplication off. Default: 2 
 dedupValue=1 dedupValue=-1 
 fields 
 Only include these fields in each result, as a comma-separated list. Possible fields: title, originalURL, linkToArchive, tstamp, digest, mimeType, linkToScreenshot, linkToNoFrame, linkToExtractedText, linkToMetadata, linkToOriginalFile, snippet, collection, language, languageConfidence. By default every field above is returned except language and languageConfidence. spellcheck isn't a result field: it asks for a spelling correction of the query, returned in suggested_query. On its own, fields=spellcheck keeps the default result fields. 
 fields=title,originalURL,linkToArchive,tstamp fields=title,spellcheck 
 titleMaxLength 
 Maximum number of characters of the title field. Longer titles are cut short and end with an ellipsis (…). 0 disables truncation. Default: 300 
 titleMaxLength=30 
 snippetMaxLength 
 Maximum number of characters of the snippet field. Longer snippets are cut short. 0 disables truncation. Default: 300 
 snippetMaxLength=100 
 timeline 
 When true, also returns a timeline with the number of matching pages per year. See Timeline . Default: false 
 timeline=true 
 yearBalance 
 Lifts the ranking of pages from the years the archive holds the fewest pages from, which would otherwise be outranked by pages from the better-covered years. Takes true (default strength, 0.5), false (no effect) or a strength between 0.0 and 1.0. Default: false 
 yearBalance=true yearBalance=0.8 
 prettyPrint 
 When true, the response is indented with line breaks, to be human-readable. Default: false 
 prettyPrint=true 
 Search for URL 
 Search by URL lists the preserved versions of a URL, from the most recent to the oldest. 
 Parameter name 
 Description 
 Examples 
 versionHistory 
 URL whose preserved versions should be listed. The protocol (http or https) is ignored. You must encode the URL with percent-encoding (URL encoding). 
 versionHistory=publico.pt OR versionHistory=http%3A%2F%2Fwww.imooty.pt/ %2FOpiniao.php%3Fsort/ %3Dlanguage%26action%3Dsort 
 from 
 Only list versions captured on or after this date. Format: YYYYMMDDHHMMSS, also accepts a shorter date, e.g. YYYY. 
 from=2005 
 to 
 Only list versions captured on or before this date. Format: YYYYMMDDHHMMSS, also accepts a shorter date, e.g. YYYY. 
 to=2006 
 offset 
 Number of versions to skip, to page through them. Default: 0 
 offset=50 
 maxItems 
 Maximum number of versions per page. Default: 50 
 maxItems=5 
 prettyPrint 
 When true, the response is indented with line breaks, to be human-readable. Default: false 
 prettyPrint=true 
 The other full-text search parameters, like fields, don't apply to the search for URL. 
 Search for metadata 
 Returns the metadata of a single preserved version. The links to it are returned in the linkToMetadata field of the other searches. 
 Parameter name 
 Description 
 Examples 
 metadata 
 Preserved version, as <URL>/<timestamp> , percent-encoded. 
 metadata=http%3A%2F%2Fwww.expresso.pt%3A80%2F%2F20000302151731 
 Extracted text 
 The text extracted from a preserved version is returned as plain text by a separate endpoint, https://arquivo.pt/textextracted . The links to it are returned in the linkToExtractedText field of the full-text search. It returns HTTP 404 Not Found when there is no text for that version. 
 Parameter name 
 Description 
 Examples 
 m 
 Preserved version, as <URL>/<timestamp> , percent-encoded. 
 m=https%3A%2F%2Fsaldanhasanches.pt%2F conteudos%2Foutros.html%2F20091218144830

 *Fields of each result, repeated for every item of response_items. 
 Timeline 
 With timeline=true, the response includes the number of matching pages per year: 
 counts : number of matching pages per year. Years without matches are kept with a count of 0. 
 impact : share of the pages archived in that year that match the query. The counts alone say little, since the archive holds many more pages from some years than from others; impact makes the years comparable. 
 When the search is bounded by from or to, the years outside that range are always 0. 
 Errors 
 Errors are returned with an HTTP error status code and a JSON body describing the error: 
 {"message":"Invalid API Request","httpStatus":400,"timestamp":"2026-10-12T14:16:19.358Z"}
 400 Bad Request : the request is invalid, e.g. it has neither q, versionHistory nor metadata, q holds a URL, or minLanguageConfidence has an unknown value. 
 404 Not Found : the requested version doesn't exist, e.g. on textextracted.

 REST from JavaScript 
 The API allows cross-origin requests (CORS), so it can be called with fetch() from any web page, to build applications that show Arquivo.pt search results without any server-side code. A complete example is available at https://github.com/arquivo/example-api . 
 The following example displays the first page of search results for the query Simone de Beauvoir : 
 <html>
 <head>
 <title>Arquivo.pt API Example</title>
 </head>
 <body>
 <div id="content"></div>
 <script>
 fetch("https://arquivo.pt/textsearch?q=simone%20de%20beauvoir&from=1996&to=20001231235959&maxItems=10")
 .then(response => response.json())
 .then(data => {
 const content = document.getElementById("content");
 for (const item of data.response_items) {
 const link = document.createElement("a");
 link.href = item.linkToArchive;
 link.textContent = item.title;
 content.append(link, document.createElement("br"));
 }
 });
 </script>
 </body>
</html>
 The callback parameter (JSONP) is no longer supported, see #1477 .
