The Graph API offers endpoints for accessing and querying this interconnected dataset, enabling users to retrieve detailed information on research products, data sources, organizations, projects, and persons. Base URL ​ https://api.openaire.eu/graph/ Two ways to query ​ The same five entities are available through two different query styles. They are separate sets of endpoints, each with its own documentation section — pick the one that fits your use case: Parameter-based Queries Filter-based Queries How you filter one query parameter per filter a single filter expression Example ?type=publication&fromPublicationYear=2023 ?filter=type:publication,from_publication_year:2023 Faceted counts — aggregations Choosing response fields — select Parameter-based Queries use one query parameter per filter. This is the style carried over from the earlier versions of the API, so it is the closest match if you are migrating an existing integration. Filter-based Queries collapse every filter into one compact filter expression, and additionally offer faceted counts and response-field selection. To move an existing integration across, see Migration from Parameter-based Queries . Each section states the API version it currently documents and links to its Swagger reference. Notes ​ Please note that the Graph API: limits offset-based paging to 10,000 results per query. For complete dataset access, use cursor-based paging — see Paging for parameter-based queries and Sorting and paging for filter-based ones — or download the full OpenAIRE Graph dataset . adheres to the terms of use of the OpenAIRE public APIs — certain (rate limit) restrictions apply.
